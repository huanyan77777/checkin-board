# 签到方案对照与动画制作

依据《全体人员及骨干志愿者大会签到方案.docx》。原 Word 和 PSD 未修改。

## 已实现

- 手机端填写姓名、部门，选择六种文字泡颜色；提供姓名泡预览与大屏展示告知。
- 颜色经过服务端白名单校验，保存至 SQLite；旧记录迁移为默认蓝色，不清空已有签到。
- 大屏使用原稿六部门插画和校徽，标题、卡片与姓名区改为独立 HTML/CSS；设计尺寸 1920×1080，整体等比例缩放。
- 未点亮区域使用柔和近黑色，签到后显示自选颜色与姓名，带轻微入场动画。没有蓝色辅助分割线。
- 单部门每页24格，超出每8秒轮播；人数显示总数。名单存在时以必到名单计算完成状态；没有名单时明确标记占位格，不假装知道应到人数。
- 全屏 F，退出 Esc，隐藏/恢复工具栏 H。断线时保留已收到的名字，并尝试重连。

## 当前简化与未完成

- 当前是规则网格，不是图标内部的不规则遮罩分区。图标目前保留完整静态插画，没有拆成书页、齿轮等可动零件。
- 学习部、办公室用圆角方泡；体育部、宣传部用椭圆泡；文艺部、权益部暂用带音符/爱心标记的文字泡，不是完整音符/爱心轮廓。
- 不自动播放下表复杂完成动画。完成状态仅显示应到人员已全部签到，未制作收字、变形等效果。
- 方案二的身份字段、负责人外圈、骨干志愿者内圈、空缺填充和两秒后环绕旋转暂未启用；它与方案一是备选，不同时启动。
- 二维码立牌需最终 HTTPS 域名确定后生成，不能用本机 localhost 二维码作为现场入口。
- 现有系统以姓名+部门去重，同部门同名仍需在正式使用前解决身份区分；本次不宣称完成整个生产验收。

## 六部门复杂动画制作清单

| 部门 | 原方案效果 | 需要的素材与工具 |
|---|---|---|
| 学习部 | 姓名聚集到书中、合书、重新展开，纸飞机带星星飞出 | Illustrator/Figma 拆出封面、左右书页、飞机、星星；After Effects 做开合和路径动画 |
| 办公室 | 姓名跳入信封，齿轮渐显旋转 | Illustrator/Figma 分离信封前片、后片、封口、齿轮；GSAP 可以完成，AE 也可 |
| 文艺部 | 音符泡推动两只麦克风靠近、交叉并出现音符 | 两支独立麦克风与音符 SVG；GSAP 做路径与旋转，不必使用物理引擎 |
| 体育部 | 姓名进奖杯，篮球和羽毛球从两边飞来 | 奖杯、篮球、羽毛球单独 SVG；GSAP 或 AE 做弹跳和轨迹 |
| 宣传部 | 镜头漩涡吸入姓名，画笔从中出现并留下笔迹 | Illustrator 分离相机、镜头、画笔；AE 更适合漩涡与复杂笔迹，部分特效未必可导出 Lottie |
| 权益部 | 小爱心融入大爱心，大爱心变成相握的手 | Illustrator 重绘可变形路径，AE 做形变；也可用 Rive 制作状态转换 |

不是浏览器绝对做不了，而是当前完整位图没有可单独控制的部件，直接旋转整张 PNG 无法得到这些动作。

## 推荐工具组合

首选 Illustrator + After Effects；Figma 可代替 Illustrator 做简单矢量拆件与布局。

- Figma：排版、颜色、简单 SVG 部件、动画分镜。Smart Animate 用来演示交互，不能直接当正式签到程序的动画运行。
- Illustrator：复杂路径、描边、拆件、爱心/握手等形状整理。比 Photoshop 更适合这些矢量部件。
- After Effects：完整时间轴、遮罩、书本开合、漩涡和形变。简单矢量动画可通过 Bodymovin/Lottie 导出，须用网页播放器验证支持的效果。
- Photoshop：保留或修整原位图，不是本项目动画制作的主工具。
- GSAP/SVG：由前端控制真实姓名泡的聚集、轨迹、跳跃及旋转。负责人外圈/志愿者内圈的方案二适合直接代码实现，无需录成视频。
- Rive：适合想做可交互矢量动画和状态机的替代路线，但需要另学编辑器和接入运行库。

## 给素材制作人员的交付要求

每部门一份分层源文件（AI/FIG 与 AEP），并导出独立透明 SVG/PNG 部件。建立统一坐标系，例如 600×400；保留清晰图层名和旋转中心。约3–5秒，无声音，首尾能衔接静态图。

不要将真实签到姓名烘焙进动画视频。姓名数量和颜色是运行时数据，应继续由网页控制；先让网页姓名泡汇聚/淡出，再衔接预制图标动画。

优先交付可运行的 Lottie JSON + 所需图片并附参考 MP4。若特效不受 Lottie 支持，可交付透明 WebM（目标浏览器实测）或透明 PNG 序列；MP4 通常不带透明通道，只适合整块不透明播放。

所有字体、图片及运行库随站部署，不依赖境外 CDN。验收时检查透明边缘、不同人数、重复触发、断线重连、减少动态效果设置。
