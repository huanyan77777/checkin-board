# 办公室完成动画接入

办公室的完成状态由现有 departmentStats.complete 决定（包括自动达标和管理员手动设置）。完成后，部门卡片保留标题、实际人数及应到人数，下方姓名格替换为 SVG 动画。其他部门保持原样。

动画播放一次后定格；分页或 SSE 更新会续接时间轴，不重复从头播放。取消完成状态会恢复姓名格，再次完成或重新打开大屏会重新播放。启用系统减少动态效果时直接显示完成画面。

入场姓名泡取该部门前六名真实签到者，不足六名隐藏多余泡，不使用样片的虚构姓名。这些泡只是完成动效，不替代控制台中的完整签到记录。独立样片仍保留在 /office-preview.html。

SVG 加载失败时退回原姓名格。此次接入不修改签到数据或后台状态。
