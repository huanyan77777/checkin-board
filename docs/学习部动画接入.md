# 学习部完成动画

手绘 SVG：姓名泡汇入蓝色书本 → 单页跨过书脊翻动 → 珊瑚色书签、金色星星亮起 → 绿色完成徽章定格。约五秒，沿用办公室的绿色部门标题与完成标签，图形下方不重复显示文字。

正式入口 `/screen` 仅在学习部实际完成时播放。自动达标、手动完成均使用现有 departmentStats.complete。取消完成恢复姓名格，再次完成重新播放；SSE 和分页刷新续接时间轴而不重播。减少动态效果模式直接显示最终画面。

只读效果入口 `/screen?preview=learning` 在当前页面临时展示学习部完成动画，顶部明确标记预览，不保存完成状态，不添加签到记录。所有人数仍取真实数据。刷新页面可以重看，回到 `/screen` 即退出预览。

大屏动效使用学习部前四名真实签到者；不足四名隐藏多余姓名泡，不使用 SVG 源文件里的示例名字。没有学习部签到记录时，预览仍显示翻书、星星和徽章，但不显示虚构姓名。所有签到者仍在控制台管理。

素材文件：`public/animations/learning-complete.svg`。与办公室动画共用时间轴保持逻辑，但分别记录完成时间。加载失败保留原姓名格。
