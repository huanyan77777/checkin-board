# 六部门完成动画

六个部门均使用手绘 SVG，无需额外图片服务或动画库。完成状态显示为绿色部门标题与「签到完成」标签，图形下方不重复放字。

| 部门 | 完成动效 |
| --- | --- |
| 学习部 | 姓名汇入书本、翻页、星星与完成徽章 |
| 办公室 | 姓名汇入信封、封口、齿轮旋转与完成徽章 |
| 文艺部 | 调色盘摆动、话筒升起、音符跃出与完成徽章 |
| 体育部 | 篮球弹跳、奖杯升起、星形奖章与完成徽章 |
| 宣传部 | 相机入场、镜头对焦、短暂闪光、照片滑出与完成徽章 |
| 权益部 | 盾牌展开、爱心脉动、双手托起、光环与完成徽章 |

## 触发与数据

- `/screen` 按真实完成状态触发。自动达标或管理员手动完成均适用。
- 每次由未完成变为完成时播放一次，随后定格；分页或实时更新不会从头重播。
- 取消完成后恢复姓名格；重新完成或刷新页面可重播。
- 系统减少动态效果模式下直接定格。
- SVG 加载失败时保留原有姓名格。
- 姓名泡取真实签到者：办公室最多六名、学习部最多四名、新增四部门各最多两名。不足时隐藏多余姓名泡，不写入示例签到记录。完整签到记录仍在控制台。

## 只读预览

`/screen?preview=all` 同时展示六部门完成动效。也可使用 `preview=learning|office|arts|sports|publicity|rights` 单独预览一个部门。

预览顶部会明确标记；只改变当前页面展示，不改应到人数、实际人数、名单或后端完成状态。未有签到记录的部门不显示虚构姓名。回到 `/screen` 即退出预览，刷新预览页可重新播放。

## 验证

六份 SVG 的 XML 解析、screen.js 语法检查、既有签到/部门控制/记录编辑/持久化回归测试通过。浏览器六部门预览页面无控制台错误，已核对最终构图和标题布局。
